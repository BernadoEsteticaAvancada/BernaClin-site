# BernaClin — Site

Site institucional em React + Vite inspirado no conteúdo do PDF fornecido para a BernaClin.

## Conteúdo implementado
- Hero / apresentação
- Sobre a BernaClin
- Serviços
- Antes e depois
- Indicadores
- Depoimentos
- Ofertas especiais
- Contato / WhatsApp
- Rodapé
- Menu responsivo
- Carrossel automático de depoimentos

## Executar

```bash
npm install
npm run dev
```

Depois abra o endereço exibido pelo Vite.

## Build de produção

```bash
npm run build
npm run preview
```

## Observação sobre imagens

O PDF apresenta a necessidade de fotos de clientes e imagens da clínica, mas não fornece arquivos de imagem utilizáveis no conteúdo textual extraído. Por isso, o projeto usa áreas visuais provisórias. Substitua os blocos de placeholder pelas fotos reais autorizadas da BernaClin.

## Personalização

Edite `src/main.jsx` para:
- alterar textos;
- inserir número real do WhatsApp;
- inserir Instagram;
- trocar preços;
- adicionar/remover serviços;
- inserir imagens reais.

Edite `src/styles.css` para alterar cores, tipografia, espaçamentos e identidade visual.
